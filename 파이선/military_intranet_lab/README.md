# 군 인트라넷 보안약점 실습 환경 (Secure Coding Lab)

KISA 소프트웨어 보안약점 진단가이드 기반, 발표·교육용 **의도적 취약** 웹 애플리케이션입니다.
각 메뉴에서 **취약한 버전 ↔ 안전한 버전**을 토글로 비교하며 "어떻게 뚫리고, 어떻게 막는지"를 시연할 수 있습니다.

## 실습 항목 (4종)

| # | 보안약점 | 분류 | 시나리오 |
|---|----------|------|----------|
| ① | 하드코드된 중요정보 | CWE-798 / 259 (KISA #30) | 설정 페이지에 소스 내 비밀값 노출 |
| ② | 운영체제 명령어 삽입 | CWE-78 | 관리자용 ping 점검 기능 |
| ③ | 취약한 비밀번호 허용 | CWE-521 | 신규 대원 계정 등록 |
| ④ | 반복된 인증시도 제한 부재 | CWE-307 | 인트라넷 로그인 브루트포스 |

## 실행 방법 (PyCharm)

1. PyCharm에서 이 폴더(`military_intranet_lab`)를 프로젝트로 열기
2. 터미널 또는 패키지 관리에서 Flask 설치
   ```
   pip install flask
   ```
3. `app.py` 실행 (우클릭 → Run 'app')
4. 브라우저에서 접속: **http://127.0.0.1:5000**

> 처음 실행 시 같은 폴더에 `lab.db`(SQLite)가 자동 생성됩니다.

## 발표 진행 팁

1. **취약한 버전**에서 공격 성공 장면을 먼저 시연
2. **안전한 버전**으로 전환해 동일 공격이 막히는 것을 보여주기
3. 각 페이지 하단 **"왜 취약한가 / 안전한 조치"** 설명으로 근거 제시

### 실습 ② 공격 입력 예시
- Windows: `127.0.0.1 & whoami` , `127.0.0.1 & dir`
- Linux/Mac: `127.0.0.1 ; id` , `127.0.0.1 ; ls`

### (선택) 안전한 버전에서 환경변수 설정 시연
실습 ① 안전 버전은 환경변수에서 값을 읽습니다. 예:
```
# Windows PowerShell
$env:MIL_DB_PASSWORD="S3cure!Pw"; python app.py
```
